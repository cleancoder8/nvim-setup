# Neovim setup

A copy of my current LazyVim config plus a `setup.sh` installer, so a new
machine can be brought up with the exact same setup in one command.

## Install on a new machine

Requires `git` and internet access. Neovim >= 0.11 is installed automatically if
missing (Arch: `pacman`, Debian/Ubuntu: `apt`, macOS: Homebrew).

```sh
git clone https://github.com/cleancoder8/nvim-setup.git /tmp/nvim-setup
/tmp/nvim-setup/setup.sh
```

For a non-interactive run:

```sh
/tmp/nvim-setup/setup.sh -y
```

Or straight from the repo over the network:

```sh
curl -fsSL https://raw.githubusercontent.com/cleancoder8/nvim-setup/main/setup.sh | bash -s -- -y
```

### What the script does

1. Checks for Neovim >= 0.11 and offers to install it if missing.
2. Moves any existing `~/.config/nvim` to `~/.config/nvim.bak.<timestamp>`
   (nothing is deleted).
3. Clones this repo into `~/.config/nvim`.
4. Sets up the theme:
   - On Omarchy, `lua/plugins/theme.lua` is symlinked to
     `~/.local/state/omarchy/current/theme/neovim.lua`, so theme switching keeps
     working.
   - Elsewhere, the saved snapshot in `theme/neovim.lua` (tokyonight-night) is
     installed as a regular file.
5. Runs `Lazy! install` followed by `Lazy! restore`, so plugins end up at the
   exact commits pinned in `lazy-lock.json` (a first-run install alone checks
   out branch HEAD instead). `Lazy! sync` would update everything to the newest
   commits. Use `--skip-plugins` to do this later manually.

Then just run `nvim`.

## Updating an installed config

```sh
cd ~/.config/nvim
git pull
nvim --headless -c 'Lazy! restore' -c 'Lazy! install' -c 'qa!'
```

`lua/plugins/theme.lua` is deliberately gitignored: on Omarchy it is a symlink
managed by the theme switcher, and on other machines it is generated by
`setup.sh` from `theme/neovim.lua`.

## Saving changes back

Edit files in `~/.config/nvim` as usual, then commit and push from there:

```sh
cd ~/.config/nvim
git add -A
git commit -m "describe your change"
git push
```

To refresh the saved theme snapshot for non-Omarchy machines, copy the resolved
theme file into `theme/neovim.lua` in this repo.
